우시시와 아야단의 오리지널 논리 퍼즐 · 100레벨

바로 플레이
  모바일·PC 웹앱: https://usisifan.github.io/udoku/
  Windows 다운로드: https://github.com/usisifan/udoku/releases/latest

Windows 프로그램
  Windows 10/11, 64비트 PC용입니다.
  단일 파일: Ushishi-Puzzle-Farm-0.2.0-Windows.exe를 실행합니다.
  ZIP 버전: 압축을 모두 푼 뒤 Ushishi-Puzzle-Farm.exe를 실행합니다.
  ZIP 안의 실행 파일만 따로 옮기지 마세요. 함께 들어 있는 파일이 필요합니다.
  설치, 게임 계정, 인터넷 연결 없이 실행할 수 있습니다.
  배포 파일에 코드 서명 인증서는 적용하지 않았습니다.

아이폰·안드로이드
  위 웹앱 주소를 Safari 또는 Chrome에서 열어 플레이합니다.
  아이폰: Safari의 공유 → 홈 화면에 추가.
  안드로이드: Chrome의 메뉴 → 앱 설치 또는 홈 화면에 추가.
  첫 접속에서 게임 파일이 저장되면 이후 오프라인으로도 실행할 수 있습니다.
  브라우저가 사이트 데이터를 지우면 오프라인 파일과 진행 기록도 삭제됩니다.
  웹앱에는 회원 가입이나 로그인, 광고, 분석 추적 도구가 없습니다.

첫 화면과 진행
  화면: 자동 / 어둡게 / 밝게 버튼으로 바꿀 수 있습니다. 자동은 기기 설정을 따릅니다.
  어두운 화면은 배경과 칸의 채도를 낮춘 전용 색상을 사용합니다.
  진행 초기화 버튼은 확인 후 이 게임의 완료 기록과 풀던 문제만 초기화합니다.
  초기화해도 화면과 소리 설정은 유지됩니다.
  게임 시작 / 이어서 풀기 버튼으로 플레이합니다.
  첫 레벨은 4×4이며, 구간에 따라 정답 아야단 1·4·5·6마리가 먼저 공개됩니다.
  시작 단서는 서로 다른 색 구역과 보드의 여러 방향에 퍼져 있습니다.
  시작 아야단은 목숨이나 힌트를 소모하지 않습니다.
  이전 레벨을 완료해야 다음 레벨이 열립니다. 완료한 레벨은 다시 풀 수 있습니다.
  100레벨 칸은 잠김 / 미완료 / ★ 클리어 완료를 구분합니다.
  별 표시는 100레벨 완료 기록이 있을 때만 나오며, 다시 도전해도 유지됩니다.
  진행 중에는 아래의 '첫 화면' 버튼으로 돌아갈 수 있습니다.

조작
  마우스 드래그 / 손가락으로 쓱 밀기: 지나간 칸에 흰색 X 표시.
  X에서 드래그 시작: 지나간 칸의 X 지우기.
  한 번 클릭 / 한 번 터치: X 표시 또는 지우기.
  두 번 클릭 / 두 번 톡: 아야단 놓기.
  큰 보드: '확대' → '화면 이동'을 켜서 밀어 보기. 표시할 때는 화면 이동을 끕니다.
  방향키: 칸 이동 / X 키: X 표시 / Enter 또는 Space: 아야단 놓기.
  Esc: 일시정지 / F11: PC 전체 화면.

규칙
  가로, 세로, 같은 색 구역마다 정해진 수의 아야단을 놓습니다.
  아야단은 가로·세로·대각선을 포함해 서로 붙을 수 없습니다.
  한 색의 구역은 모두 상하좌우로 연결되어 있습니다.
  상단 그림 규칙은 현재 레벨에 맞춰 1마리 또는 2마리로 바뀝니다.
  잘못 놓으면 목숨이 1회 줄고, 모두 소모하면 라운드가 끝납니다.
  1–39레벨: 힌트 2회 / 목숨 2회 / 시작 공개 1마리.
  40–59레벨: 힌트 5회 / 목숨 3회 / 시작 공개 4마리.
  60–79레벨: 힌트 6회 / 목숨 3회 / 시작 공개 5마리.
  80–100레벨: 힌트 7회 / 목숨 3회 / 시작 공개 6마리.
  40레벨부터 힌트는 이후 추론에 도움이 되는 정답 칸을 우선 공개합니다.
  잘못 쓴 X 메모는 힌트 선택에 영향을 주지 않습니다.
  새 판 기준으로 기본 추론과 구간별 힌트 한도 안에서 끝까지 풀 수 있는 경로를 검증했습니다.
  기존 40–100레벨 판에는 힌트 한도 증가분 1회를 추가하며, 이미 쓴 횟수와 기록은 유지됩니다.
  진행 중이던 라운드는 이미 쓴 힌트와 잃은 목숨을 유지하고 한도 차이만 추가합니다.
  완료 기록과 플레이 시간은 유지되며 새 시작 단서 위치만 정답으로 공개됩니다.
  새 단서로 마지막 정답이 채워지면 완료로 기록하고 다음 레벨이 열립니다.
  이미 찾은 아야단은 지울 수 없습니다. X 메모는 수정할 수 있습니다.
  '다시 시작'은 확인 후 해당 라운드를 새로 시작합니다.

레벨 구성
  1: 4×4 / 2–3: 5×5 / 4–6: 6×6 / 7–8: 7×7 / 9: 8×8
  10–24: 10×10 / 25–39: 12×12
  40–59: 14×14 / 60–79: 16×16 / 80–100: 20×20
  1–39레벨: 줄과 색 구역마다 1마리. 40–100레벨: 각각 2마리.

자동 저장
  문제, 목숨, 힌트 사용, 완료 기록은 현재 기기에 자동 저장됩니다.
  PC: %APPDATA%\시시의 퍼즐 목장\progress.json
  EXE와 ZIP은 같은 Windows 계정에서 기록을 공유합니다.
  웹: 현재 브라우저의 이 게임 전용 저장 공간.
  PC 프로그램과 웹앱, 서로 다른 기기·브라우저 간 기록은 동기화되지 않습니다.
  다른 창이나 앱으로 전환하면 플레이가 일시정지됩니다.
  v0.1.0에서 교체된 1–9레벨 기록은 초기화됩니다. 일치하는 나머지 문제 기록은
  보존되지만, 순서대로 앞 레벨을 완료해야 다시 열립니다.

제작과 검증
  100개 문제는 이 프로젝트에서 작성한 생성기로 직접 만들었습니다.
  뮤도쿠·햄도쿠 등 외부 게임의 문제 데이터는 사용하지 않았습니다.
  모든 문제의 연결 구역, 마릿수, 비접촉 조건, 유일한 정답을 검증했습니다.
  회전·반사 및 색 번호 변경으로 같아지는 중복 문제도 제외했습니다.
  초반 9레벨은 공개된 한 마리에서 분기 탐색 없이 풀이가 완료됨을 확인했습니다.
  코드, 시드, 최종 문제, SHA-256 및 검증 기록은 소스와 provenance 폴더에 있습니다.
  난도는 보드 크기와 탐색량을 기준으로 정한 초기안이며 플레이 의견으로 조정할 수 있습니다.
  캐릭터 원화는 사용자가 제공하고 확정한 우시시·아야단 이미지입니다.
  캐릭터 및 외부 런타임의 권리와 라이선스는 각 권리자에게 있습니다.
  문제를 직접 생성했다는 기록은 법적 저작권 등록이나 독점권 인증은 아닙니다.

소스에서 실행 / 빌드
  Node.js와 pnpm을 설치한 환경에서:
    pnpm install
    pnpm start
  테스트: pnpm test
  100개 문제 검증: pnpm verify
  GitHub Pages 파일 갱신: pnpm prepare:web
  Windows 패키지: pnpm dist
  GitHub Pages는 이 저장소 main 브랜치의 /docs 디렉터리만 배포합니다.
  다른 저장소나 계정 루트 사이트 설정은 사용하지 않습니다.
  첫 의존성 설치와 빌드 도구 다운로드에는 인터넷 연결이 필요합니다.
