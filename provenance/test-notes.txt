0.2.0 검증 범위

문제: 100개 모두 연결 구역, 마릿수, 비접촉 조건, 유일한 정답 검증 통과.
회전·반사 및 색 번호 변경을 고려한 중복 없음. 모든 문제에 정답 단서 한 마리.
1–9레벨은 그 단서에서 분기 없이 풀이 완료. verification.json 참조.

로직: Node.js 테스트 13개 통과. 독립적인 순열 풀이와 작은 보드 200개 비교.
목숨, 힌트, 승패, 단서 보호, 저장 복원, 순차 해금, 이전 버전 완료 기록 처리 검증.

UI: ui-tests.json 참조. 실제 Electron 앱에서 마우스 드래그·더블클릭,
첫 화면과 정지된 타이머, 무료 단서, 잠긴 레벨의 UI 및 핸들러 차단,
승리 후 재시작, 파일 저장·복원, 1레벨부터 100레벨까지 순차 진행 확인.
1160×960 PC 화면에서 보드와 조작부가 화면 안에 표시됨.

모바일 웹: 프로젝트 하위 경로에서 실제 정적 파일을 HTTP로 제공하여 확인.
Chromium 모바일 에뮬레이션 390×844 및 320×640, 가로 넘침 없음.
터치 입력 이벤트로 쓱 밀기·두 번 톡, 확대 후 화면 이동 검사.
브라우저 로컬 저장, 프로젝트 범위 서비스 워커, 오프라인 재로드 검사.
작은 세로 화면은 아래로 스크롤하여 모든 조작부를 볼 수 있음.

배포: package-integrity.json의 소스와 실제 ASAR 파일 해시 일치 검사.
packaged-startup.json / portable-startup.json은 해당 실행 파일의 시작·저장 검사.

환경과 한계
격리된 Windows 개발 계정의 Chromium 프로세스 제한 때문에 UI 및 EXE 시작
검증에서만 --no-sandbox --in-process-gpu --disable-gpu 옵션을 사용했습니다.
배포 앱 기본값에는 포함되지 않습니다. sandbox=true, contextIsolation=true,
nodeIntegration=false를 유지합니다. PC 프로그램은 외부 HTTP/HTTPS를 차단합니다.
일반 사용자 Windows 및 실물 아이폰 Safari·안드로이드 기기 테스트는 아직 하지 않았습니다.
모바일 검증은 Chromium 터치 에뮬레이션이며 실제 iOS 인증을 의미하지 않습니다.
코드 서명 인증서는 적용하지 않았습니다. 기록은 기기 간 동기화되지 않습니다.
